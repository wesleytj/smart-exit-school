# Definition of Ready

Antes de iniciar qualquer implementação, a IA deve validar que a tarefa está pronta para desenvolvimento.

---

# Checklist

## Escopo

✓ Existe uma descrição clara da tarefa.

✓ O objetivo está definido.

✓ O resultado esperado está claro.

---

## Git

✓ Existe uma Issue.

✓ Existe uma Branch apropriada.

---

## Arquitetura

✓ A implementação respeita a arquitetura existente.

✓ Não existe conflito com ADRs.

---

## Documentação

✓ Há documentação suficiente para iniciar.

Caso contrário, a IA deve solicitar esclarecimentos.

---

## Classificação

A tarefa foi classificada como:

- Feature
- Bug
- Refactor
- Documentation
- Infrastructure
- Research
- Spike
- Hotfix

---

# Regra

Caso qualquer item esteja incompleto, a implementação não deve começar.
