Formato obrigatório:

tipo(escopo): descrição

Exemplos:

feat(auth): implement tenant authentication

fix(panel): correct logout redirect

docs(aads): add git workflow

refactor(repository): simplify school service

test(auth): add platform admin tests

chore(ci): update github actions

Regras

- verbo no imperativo
- inglês
- primeira letra minúscula
- máximo 72 caracteres
- um único objetivo por commit
