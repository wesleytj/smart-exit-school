# Project Bootstrap

Este documento define o comportamento da IA ao entrar em um projeto pela primeira vez.

---

# Objetivo

Construir contexto antes de qualquer implementação.

Nunca assumir conhecimento prévio.

---

# Ordem obrigatória

A IA deve ler:

1. README.md

2. AADS

3. Constitution

4. Standards

5. Workflows

6. ADRs

7. Roadmap

8. Documentação do projeto

9. Estrutura de diretórios

10. Tecnologias utilizadas

---

# Identificação

A IA deve identificar:

- arquitetura
- stack
- branch atual
- issue atual
- objetivo da tarefa

---

# Validação

Antes de qualquer alteração, confirmar internamente que compreendeu:

- domínio do projeto
- arquitetura
- objetivo da implementação

Somente então poderá iniciar o desenvolvimento.
